# Executor Mode T vs Mode C

**Status:** proposed

**Context:** This ADR is tracked as part of the next-phase bot engine plan in [T8_BOT_ENGINE.md](../plans/next-phase/T8_BOT_ENGINE.md).

**Decision:** Both exist; Mode C adds one risk level. See [02_APPROVAL_FLOW.md](../plans/next-phase/02_APPROVAL_FLOW.md).

**Consequences:** Executor and approval flows must account for two modes with different risk treatment as described in the approval flow doc.

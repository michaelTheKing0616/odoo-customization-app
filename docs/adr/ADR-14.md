# Supported Odoo versions

**Status:** accepted

**Context:** This ADR is tracked as part of the next-phase bot engine plan in [T8_BOT_ENGINE.md](../plans/next-phase/T8_BOT_ENGINE.md).

**Decision:** Community 20, 19, 18, 17 are GA. 16 is experimental. Majors at or below 15 are refused. The Odoo 20 compose file is not built yet.

**Consequences:** Compatibility and sandbox tooling must align with this version matrix; Odoo 20 local stack remains a planned gap until compose is added.

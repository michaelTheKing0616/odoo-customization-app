# Ingenium Builders — IDEA

## Goal
Best-in-class builders for Odoo layouts and prints: View Designer (priority), Reports/PDF, then App Studio and Draft Studio on the same foundation. Beyond Odoo Studio in fidelity, safety and craft.

## References (blend, expressed in brand/ingenium-v2, never copied)
- Figma editor: primary. Canvas + layer tree + property panel, precision, keyboard speed, comments.
- Webflow Designer: structure-true editing (nesting = Odoo sheet/group/notebook/page), drag rules.
- Framer: motion, instant preview, calm defaults, premium feel.
- Stripe dashboard: reports, PDF/invoice previews, dense data made clear.
- Not Linear.

## Foundation
One shared view engine: renders real Odoo arch (form/list/kanban/QWeb report) faithfully for 17/18/19/20 with live records from the connected DB. Edits saved as minimal inherited views (xpath), never overwriting stock.

## View Designer
- Live-data canvas; flip records; stress-test longest/emptiest record.
- Preview as role (rep / manager / portal); hidden and read-only shown per group.
- Plain-words conditions ("Show when Stage is Won") compiled to Odoo rules; badges on conditional fields.
- Version view (17–20 side by side, incompatibility flags); desktop/tablet/phone.
- Upgrade-safe check + before/after diff.
- Usage-driven suggestions: unused fields (fill rate), order by real use, hidden required fields.
- Layout checks (crowded tabs, labels, accessibility) with one-click fixes.
- History: undo, named versions, compare, revert; preview-then-promote publish; pinned comments.
- Command bar + plain-English edits (AI proposes, code validates).

## Reports / PDF
- Drag-and-drop designer, proofed live via Odoo's own PDF renderer on real records.
- Page-break and overflow warnings.
- Language / currency / company previews; paper size, header/footer visually.
- Brand kit once, applied to all reports and mail templates.
- Before/after PDF comparison; starter gallery (invoice, quote, delivery).

## Across all builders
Shared visual language and motion (ingenium-v2), plain-language copy, same history/preview/safe-publish flow.

## Build order
1. Shared view engine  2. View Designer  3. Reports/PDF  4. App Studio + Draft Studio adopt it.
Then SPEC.md, then four stages (structure / logic / styling / polish), Tope's go after each.

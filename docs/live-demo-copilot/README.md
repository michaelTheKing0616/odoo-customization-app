# Live Demo Co-Pilot

Real-time Odoo Q&A assist for client demos/trainings.

**This branch:** consent/disclosure + Attendee capture + Stage 1/2 + **presenter overlay** + **presenter ignore-list**.  
**Next:** first internal pilot on a real meeting (`PILOT.md`).

See [PROGRESS.md](./PROGRESS.md) and [ATTENDEE.md](./ATTENDEE.md).

### Presenter overlay

From a live session, click **Open presenter overlay** (pops `/live-demo-copilot/overlay?session=…`).  
Share the Zoom / Meet / Teams window or your Odoo tab only — put the overlay on another display and **never** share that window.

### Pilot

Follow [PILOT.md](./PILOT.md). Set your Zoom/Meet display name so your own questions do not trigger the overlay.

Odoo Expert Bridge

Adds a Settings menu entry that opens the No-Code Customization app Expert panel (?expert=1) with optional record context.

After install, set system parameter expert_bridge.base_url to your web app URL. Local dev is often http://127.0.0.1:3002; Docker deploy uses http://127.0.0.1:3000. Set expert_bridge.connection_id to the UUID from /connections/{id} if auto-resolve picks the wrong row.

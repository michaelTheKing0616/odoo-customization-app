# SK-META-CLARIFY

## When to use / When NOT to use

Use when the request matches: Ask only material questions, at most three, with a recommended default.

Do not use this skill to widen a Bot Grant, to approve a plan, or to call apply.

## Procedure

Ask at most three multiple-choice questions. Mark a recommended default and the consequence of each option. Never ask for a fact introspection can supply. Record the answer and do not ask it again in the same run.

## Guardrails

Refuse R4 targets. Group-less access, module uninstall, raw delete, lock dates, and protected parameters stop the plan.

## Verification

The engine reports verified only after post-conditions pass. This skill does not declare success.
